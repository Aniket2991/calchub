# CalcHub — All-in-One Calculator

Production-oriented Next.js starter for a calculator website.

## Current features
- Basic calculator
- Scientific calculator
- Percentage calculator
- EMI calculator
- SIP calculator
- GST calculator
- Discount calculator
- BMI calculator
- Age calculator
- Unit converter
- Search + category filters
- Responsive mobile-first interface
- Ad placeholder areas
- About / Privacy / Terms pages
- robots.txt and sitemap generation
- SEO metadata

## Run
```bash
npm install
npm run dev
```

## Before launch
1. Replace `YOUR-DOMAIN.com` in `app/sitemap.ts` and `app/robots.ts`.
2. Add your real business/contact information.
3. Create a Google AdSense account and add the correct publisher code after approval.
4. Add Google Search Console.
5. Add analytics only after configuring the required privacy disclosures.
6. Create individual SEO landing pages for each calculator.
7. Test every calculation with known examples before publishing.

## Important
Financial and health calculators should clearly state that results are estimates/informational and should be verified before consequential decisions.
